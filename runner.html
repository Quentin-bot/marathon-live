3. URL à coller dans OwnTracks (recommandé)

  1. Installe OwnTracks (App Store, gratuit).
  2. Réglages ⚙️ → Mode : HTTP → URL : colle l'adresse ci-dessus.
  3. Autorise la localisation « Toujours » (Réglages iPhone → OwnTracks → Position).
  4. Le jour J, sur la carte d'OwnTracks, passe le mode de suivi sur « Move » (envoi fréquent).

OwnTracks continue d'envoyer ta position écran verrouillé, téléphone dans le brassard.
